# Niyu

A programming language and compiler built from scratch using C++20.

## Features

- Lexer
- Parser
- Abstract Syntax Tree
- Semantic Analysis
- Intermediate Representation
- Code Generation

## Build

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## Run
./build/niyu

## Requirements
``` txt
C++20 compiler
```
